# OASIS 2026 presentation pages

Static GitHub Pages publishing branch for the presentation and workflow overview.

- `index.html`: link hub
- `talk_slides.html`: Quarto Reveal.js presentation
- `talk_slides_files/`: required Quarto/Reveal.js scripts and styles
- `figs/`: presentation images
- `flowchart_structure.en.html`: standalone workflow overview

To update, replace the rendered HTML and corresponding resources, then push to
`codex/presentation-pages`. GitHub Pages publishes this branch from its root.
